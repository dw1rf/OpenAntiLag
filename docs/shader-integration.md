# Интеграция SCSKiller

Open AntiLag 0.6.0 управляет отдельным неизменённым CLI официального SCSKiller 1.2.5 через стандартные потоки. Это ограниченная интеграция, а не полная копия SCSKiller.

- Исходники: https://github.com/BlueHeisenberg/SCSKiller
- Проверенный upstream commit: `bf2571af3db4d1d3c49aeb05cda170571eae0704`.
- Архив: `https://github.com/BlueHeisenberg/SCSKiller/releases/download/v1.2.5/SCSKiller-1.2.5-Portable.zip`.
- SHA-256: `a039c2fa82d36e78c82f5eaac436d46459c791bd1ff47e27be95037db2e4897c`.

## Граница интеграции

Разрешены только `scan`, `status <id>`, `cache get` и интерактивная `queue`. Для каждой выбранной игры отправляются `add <id>`, `start`, `list`; при конечном статусе или отмене — `quit`. Успех требует строки `Done` именно для выбранного ID и успешного завершения процесса. Один exit code 0 не считается подтверждением компиляции. ID проверяются; оболочка команд не используется.

Каждый процесс вместе с потомками принадлежит Windows Job Object с KILL_ON_JOB_CLOSE. При обычной отмене компиляции CLI получает `quit` и завершает текущую работу штатно. После выхода владельца Job Object закрывается, чтобы его оставшиеся потомки не держали приложение и перенаправленные потоки. Процессы других приложений по имени не завершаются. Аварийное закрытие приложения может прервать незавершённую работу движка.

Системные операции, GPU-настройки, обновление EXE и операции шейдеров разделяют блокировку интерфейса. Файловая блокировка дополнительно исключает одновременное использование одной папки модуля несколькими экземплярами Open AntiLag.

## Установка и настройки

Архив не входит в релиз Open AntiLag. Загрузка использует HTTPS и ограниченный список адресов GitHub, лимит размера и закреплённый SHA-256. Распаковка выполняется во временную папку с проверками путей, повторяющихся имён, символических ссылок и размеров. После успешной проверки папка перемещается на место; существующая установка не перезаписывается.

Portable-маркер и `data/migrated` предотвращают импорт чужого профиля SCSKiller. Рекордер, автозапуск, автоматическая подготовка после изменения драйвера, автоматическое обновление модуля, community-база, отправка записей и фоновая проверка отключены. Установлены Idle, максимум 4 потока и бюджет памяти native-компилятора 2 ГБ; последний не ограничивает всю память драйвера/процессов.

Перед каждой операцией проверяются архив, штатные файлы CLI/native, отсутствие reparse points, маркер изоляции и обязательные ограничения настроек. Состояния с рекордером или офлайн-записью отклоняются. Это проверка целостности штатной установки, а не защита от локального администратора или скомпрометированного графического драйвера.

Не запускаются GUI SCSKiller, команды установки рекордера, изменения NVIDIA Auto Shader Compilation, удаления кэша, изменения лимита кэша, регистрации задач и ввода ключей. Правила совместимости/кодеки upstream могут загружаться самим движком; отсутствие любых сетевых обращений не обещается.

## Лицензии и проверки

Open AntiLag сохраняет MIT-лицензию своего кода интеграции. Отдельный SCSKiller имеет GPL-3.0-or-later и исключения для перечисленных upstream компонентов. Официальный архив сохраняется целиком вместе с `current/LICENSE`, `LICENSE-EXCEPTION.txt` и `THIRD-PARTY-NOTICES.md`. Источник и версия указаны выше; исходники upstream не копируются и не линкуются в EXE Open AntiLag.

Автоматические тесты проверяют парсинг/ID, защиту распаковки и настройки, контроль успешного завершения, отмену, UTF-8 и удаление только собственных дочерних процессов. UI проверен с подменой движка. Настоящий архив и CLI проверены; реальное сканирование обнаружило 10 игр на NVIDIA RTX 4070 Ti. CS2 определён как Unsupported, Cyberpunk 2077 — NeedsRecording, поэтому подготовка этих игр в интерфейсе недоступна. Реальная компиляция игры, AMD и все поддерживаемые версии Windows не проверены.
