# Новый интерфейс игрока — версия 0.7.0

Вместо стартового набора технических вкладок приложение открывает главную страницу с выбранной игрой, состоянием профиля и кнопкой применения/восстановления. Боковая панель содержит игры, оптимизацию, результаты, настройки и восстановление. Старые восемь разделов доступны через «Настройки → Дополнительно» и используют прежние контроллеры и журналы.

## Что выполняют профили

- Стандартный: копирует текущий план питания с сохранением исходных параметров и включает Game Mode.
- Соревновательный: дополнительно отключает запись Xbox, включая ручные клипы.
- Пользовательский: использует галочки технической страницы Windows. Перед применением показывается состав изменений. HAGS, BCD и другие системные параметры требуют отдельного выбора и, где необходимо, UAC/перезагрузки.

Применение не является измерением прироста FPS. Автоматический профиль не меняет GPU, DNS, QoS, BCD/HAGS, таймер или приоритеты процессов. CPU/RAM в простом интерфейсе — мониторинг; автоматического ограничителя фоновых процессов здесь нет.

## Игры и автоматическое восстановление

Поиск читает локальные Steam libraryfolders/appmanifest. Другие магазины поддерживаются ручным добавлением EXE. Обложки берутся локально; при отсутствии используется значок/текст. Для CS2 определяется точный путь game/bin/win64/cs2.exe. Если EXE неоднозначен, его нужно выбрать вручную.

Выбор игры и профиля сохраняется локально в `%LOCALAPPDATA%\OpenAntiLag\player-library.json`. Автоматическое применение требует отдельного согласия для игры и проверенного пути EXE. Изменение профиля снимает прежнее согласие. Ошибка сохранения запрещает новые автоматические применения.

Для стандартного и соревновательного профилей с известным EXE кнопка применения создаёт игровую сессию: если игра ещё не запущена, программа ждёт её запуска, затем восстанавливает свой базовый профиль после выхода. Пользовательский профиль и применение без известного EXE восстанавливаются вручную; подтверждение поясняет это заранее.

Журнал `%LOCALAPPDATA%\OpenAntiLag\game-session.json` связывает сессию с точным идентификатором созданного плана. После перезапуска можно восстановить профиль завершившейся игры, если владение однозначно. Незавершённая запись применения или другой идентификатор требуют ручной проверки: чужой профиль не откатывается. Обычный выход приложения также пытается восстановить принадлежащую сессии базовую настройку. Ручное отключение подавляет автоматическое повторное применение до завершения текущего запуска игры.

## Сеть, GPU и результаты

Простая интернет-проверка отправляет ICMP только к подтверждённому пользователем диагностическому узлу. Это не ping игрового сервера и не доказательство потерь игрового UDP. Расширенные средства сети, экспорт, QoS, DNS и необязательный NextDNS сохранены.

Ограничитель фоновой отправки использует штатный исходящий QoS для выбранного EXE; загрузку он не ограничивает. Запись в журнале не доказывает непрерывное действие политики на любой Windows.

Простые GPU-профили используют прежние глобальные контроллеры NVIDIA/AMD. «Стандартный» восстанавливает сохранённые исходные значения. Для плавности NVIDIA требует введённого пользователем FPS; AMD не включает FreeSync и не устанавливает эквивалентный лимит автоматически. Reflex автоматически не настраивается. Точное содержимое и восстановление доступны в подробностях.

Результаты показывают фактические действия и доступные CPU/RAM/ICMP-измерения. FPS, 1% Low и frametime недоступны: проверенный сборщик не подключён. Сохранённый профиль GPU означает подтверждение при применении, а не непрерывную проверку драйвера.

## Восстановление и античиты

Единое восстановление последовательно вызывает независимые контроллеры Windows, NVIDIA, AMD, QoS и DNS. Частичная ошибка сохраняется как ошибка; отмена UAC останавливает последовательность. Удалённые списки NextDNS и подготовленный кэш шейдеров этим действием не возвращаются.

Гарантии отсутствия банов и официальной совместимости с FACEIT/VAC/Vanguard нет. Наличие процесса FACEIT определяется эвристически, это не сертификация. При его обнаружении простое применение GPU и ограничителя сети блокируется. Интеграция SCSKiller оставляет рекордер и установку DLL в игры отключёнными. Предупреждение античита нельзя обходить. Правила FACEIT: https://support.faceit.com/hc/en-us/articles/360015788779-What-is-deemed-to-be-a-cheat

## Проверки и границы

Сборка .NET Framework 4.8 x64, C# 5. Основные 179 тестов используют fake-хосты для записей Windows/GPU/сети. Проверяются владение сессией, реальное применение существующим Engine, откат, занятая операция, UAC cancellation, Steam manifest и сохранение согласия. UI-check дополнительно нажимает основную кнопку на fake-хосте, проверяет семь маршрутов, восемь сохранённых технических страниц, пропуск мастера и масштабирование 100/125/150/200%. Это программное масштабирование; физическая смена DPI монитора не выполнялась.

Реальное назначение DNS/QoS, запись GPU на разных драйверах, настоящий NextDNS-аккаунт и совместимость с античитами не проверены. Ранее проверены только чтение сетевых API, loopback ICMP/TCP и CPU/RAM. Прирост производительности не заявляется.

В одном промежуточном прогоне старый MachineTests встретил ошибку файловой блокировки временного XmlStateStore при File.Replace; повторный полный прогон прошёл. Новый UI-check нашёл исключение при создании пустого списка игр в мастере: исправлен выбор SelectedIndex только для непустого списка.

Пакет релиза включает EXE, документацию и контрольные суммы. Проверки и ограничения выше относятся к этой сборке; публикация сама по себе не расширяет проверенную совместимость.
