Open AntiLag 0.5.3 • NVIDIA • глобальные настройки
Проверено 10.10.2026: RTX 4070 Ti / 617.42 (чтение и временная сессия без сохранения).

Во вкладке NVIDIA выберите режим и нажмите «Применить NVIDIA». Исходные изменяемые значения будут сохранены; «Восстановить NVIDIA» возвращает их. Для другого набора сначала выполните восстановление. Закройте игры перед применением.

Будут применены глобальные параметры NVIDIA:

Очередь кадров → 1 (Low Latency On)
Ultra Low Latency → Выкл. (используется On)
Low Latency в панели → Вкл.
Управление питанием → Нормальный / Optimal power
Частота обновления → Наивысшая доступная
Лимит FPS → 141
Фоновый лимит FPS → Выкл.
Потоковая оптимизация → Авто
Тройная буферизация OpenGL → Выкл.
Ambient Occlusion → Выкл.
Анизотропная фильтрация → Управление от приложения
Сглаживание — режим → Управление от приложения
FXAA → Выкл.
Сглаживание — прозрачность → Выкл.
Transparency multisampling → Выкл.
Гамма-коррекция сглаживания → Вкл.
MFAA → Выкл.
Качество фильтрации → Качество
Анизотропная оптимизация → Выкл.
Трилинейная оптимизация → Вкл.
Отрицательное отклонение УД → Привязка / Clamp
Вертикальный синхроимпульс → Вкл.
Глобальная политика G-SYNC → Полноэкранный режим
Технология монитора → Разрешить G-SYNC
Запрос технологии монитора → Разрешить G-SYNC

Перезапустите игры после применения. Программные профили могут переопределять глобальные значения.
Кэш шейдеров, DSR, Image Scaling, CUDA, PhysX, разрешение и герцовка здесь не меняются. Reflex включается в игре.
G-SYNC монитора должен быть настроен заранее. Укажите FPS ниже его герцовки; выключите другие лимитеры. Эта кнопка задаёт политику 3D, а не проверяет поддержку VRR дисплеем.

Этот TXT описывает основной набор с выключенными дополнительными флажками; лимит 141 FPS в режиме G-SYNC приведён как пример для 144 Гц. В приложении укажите свой лимит.

Ограничения: аппаратная проверка постоянного сохранения не выполнялась. Некоторые интерфейсы Low Latency недокументированы; при несовместимости приложение сообщает ошибку и сохраняет копию для восстановления. Новые версии драйвера требуют повторной проверки.
