# Open AntiLag 0.6.1 — отдельные системные опции и исправления интерфейса

На вкладке «Система» добавлены пять независимых галочек: HAGS, приоритет активных приложений, автоматический источник часов BCD, платформенный тик и отключение динамического тика. По умолчанию все выключены; применяются основной кнопкой только после явного выбора.

Исходные значения выбранных настроек сохраняются до записи, включая отсутствие параметра. Требуются UAC и перезагрузка после изменения/восстановления. При ошибке выполняется попытка отката. HAGS и приоритет отдельно не требуют доступа к BCD/провайдеру BitLocker. При выбранных BCD и активной либо неизвестной защите BitLocker запись блокируется.

BCD — отладочные настройки, которые могут вызвать сбои и проблемы загрузки; прирост производительности не гарантирован. HAGS требует поддержки GPU/драйвера: успешная запись значения не подтверждает фактическую активацию. Перед откатом приложения на 0.6.0 и старее восстановите системные настройки в 0.6.1 — старые версии не читают системный журнал версии 2.

Исправления интерфейса:

- Выбранная игра в «Шейдерах» выделяется яркой полосой даже после перехода на кнопку. Кнопка показывает число выбранных игр.
- Фоновое чтение состояния профиля больше не блокирует NVIDIA/AMD/шейдеры. Реальные операции применения по-прежнему выполняются по одной.
- Открытие NVIDIA/AMD больше не запускает скрытое чтение. Для этого есть отдельная кнопка «Прочитать».
- Полосы прокрутки на NVIDIA/AMD приведены к тёмной теме.

Проверены сборка, 117 автоматических тестов и UI, включая все 32 сочетания системных опций, частичные ошибки, откат, отмену UAC, выделение без фокуса и работу GPU во время фонового чтения. Реальные системные параметры ПК при тестах не менялись; применение BCD/HAGS на разных сборках Windows и перезагрузка после него не проверялись.

Функции шейдеров из 0.6.0 сохранены. CS2 в используемом SCSKiller 1.2.5 не поддерживается. Обновление доступно через встроенную проверку; без выбранных системных галочек профиль работает как прежде.
