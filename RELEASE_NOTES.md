# Open AntiLag 0.4.0 beta 1 — системный профиль

Основная кнопка «Включить профиль» теперь включает BCD/таймеры, запрос HAGS и системные приоритеты. Отдельной галочки для них нет. Добавлены запрос прав администратора, сохранение исходных значений в защищённом системном журнале, проверка записи и восстановление при ошибке. После изменения системных значений показана необходимость ручной перезагрузки.

Точно: удаляется переопределение useplatformclock, useplatformtick=yes, disabledynamictick=yes; HwSchMode=2; Win32PrioritySeparation=42 (0x2A). Устройство HPET не отключается, приоритет процесса CS2 не меняется. Активная/неизвестная защита BitLocker блокирует изменение BCD; защита автоматически не отключается.

**Экспериментальная сборка:** эти BCD-параметры предназначены для отладки. Улучшение FPS/input lag не доказано; возможны ухудшение стабильности, нагрева и производительности. Не распространяйте как проверенное средство устранения задержки.

Проверено: 49 тестов с имитацией Windows, UI-сценарий включения/отключения, обычная и узкая раскладки, увеличенные шрифты. Реальная запись BCD/HAGS и загрузка после неё ещё не проверены. Эта beta не заменяет стабильный релиз 0.3.0.

Windows 10/11 x64, .NET Framework 4.8. EXE без установщика и цифровой подписи; исходники MIT. Завершите старую копию в трее. Старый активный профиль сначала восстановите, затем включайте новый. Перед возвратом к 0.3 отключите профиль в 0.4 — старые версии не знают системный журнал. После смены пути EXE обновите автозапуск.
