# v0.3.0 — спокойный тёмный интерфейс

- Новая сине-серая палитра и тёмный системный заголовок Windows.
- Читаемый текст в заблокированных настройках активного профиля.
- Перенос описаний, адаптивная высота карточек и прокрутка в небольшом окне.
- Кнопки включения и восстановления остаются доступны при изменении размера.
- Поведение игрового профиля и формат резервных копий 0.2 сохранены.

Проверено: 27 тестов отката, сценарий включения/отключения через UI с имитацией Windows, раскладка обычного и уменьшенного окна, увеличенные шрифты/размеры 150% и 200%. Windows приняла параметры тёмной рамки. Проверки не включали реальную оптимизацию компьютера и замеры FPS/input lag.

## Установка

Завершите старую копию через меню значка в трее и запустите OpenAntiLag.exe. Установка не требуется. Нужны Windows 10/11 x64 и .NET Framework 4.8. Автозапуск при необходимости включите заново из нового расположения.

Профиль не гарантирует прирост производительности. EXE не подписан цифровой подписью; полный исходный код доступен в репозитории.
