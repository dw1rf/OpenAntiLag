# Open AntiLag 0.7.1 — исправление мигания интерфейса

При переключении разделов страницы больше не удаляются из контейнера и не добавляются заново. Сохраняются HWND и позиция прокрутки. Повторное нажатие на текущий раздел не переключает видимость. Добавлена буферизация родительской поверхности с дочерними элементами и контейнеров карточек.

Фоновые события больше не перерисовывают скрытые страницы: актуальное состояние отображается при открытии. Изменения текста и элементов состояния группируются в один проход раскладки.

Проверки: 179 автоматических тестов; расширенный player UI-check проверяет повторные переходы по семи разделам, постоянство parent/HWND, отложенное обновление скрытых страниц, сохранение прокрутки и повторный выбор текущей страницы. Проверяется масштабирование 100/125/150/200%. Старые функции и правила восстановления сохранены.

# Open AntiLag 0.7.0 — новый интерфейс игрока

Добавлены боковая навигация, главная страница, библиотека Steam/ручных игр, мастер настройки и простые карточки оптимизации. Основная кнопка вызывает существующий Engine. Стандартный профиль сохраняет параметры плана питания и включает Game Mode; соревновательный дополнительно выключает запись Xbox. Пользовательские системные настройки доступны в подробностях с просмотром состава изменений.

Применение стандартного/соревновательного профиля для известного EXE связано с запуском игры и откатом после выхода. Автоматизация требует отдельного согласия и проверенного EXE. Запись сессии проверяет владение планом; неоднозначные состояния требуют восстановления вручную. Ручное отключение предотвращает повторное применение в текущей сессии.

Все прежние модули и журналы сохранены в «Настройки → Дополнительно». Единое восстановление проверяет каждый модуль и не сообщает полный успех при частичной ошибке. Результаты не выдумывают FPS и прирост. Официальная совместимость с античитами не подтверждена, гарантии отсутствия банов нет.

Проверки: 179 автоматических тестов без реальной перенастройки Windows; отдельные проверки старого и нового интерфейса, включая программное масштабирование 100/125/150/200%. Реальные записи GPU/DNS/QoS и античиты не проверялись. Подробности: [описание интерфейса](docs/player-ui-redesign.md).

Пакет релиза: OpenAntiLag.exe, ZIP с документацией и контрольные суммы SHA-256.

## Сетевые модули предыдущей локальной итерации 0.7.0

Добавлены вкладки «Сеть», «Трафик», «DNS», «Статистика». Существующие системные/GPU-профили, шейдеры, восстановление и защищённое автообновление сохранены. Вкладки переносятся на несколько строк.

- Асинхронный ICMP: current/min/max/mean/median/P95, jitter |ΔRTT| и σ RTT, число диагностических проб без ответа; TCP fallback отделён от packet loss. Интервал 1–60 с, сеанс 5–3600 с, отмена, ограниченная история, CSV/JSON и график.
- Интерфейсы Ethernet/Wi-Fi/виртуальные, IPv4/IPv6, MTU, скорости линка и счётчики; IPv4-маршрут к выбранному диагностическому адресу и уведомления о смене. DNS и шлюзы проверяются только после отдельного разрешения.
- Процессы игр, включая CS2, TCP/UDP endpoint-таблицы IPv4/IPv6 по PID. Для UDP отображаются только сведения, которые действительно даёт Windows. К адресам игр нет автоматических проб.
- QoS ActiveStore для явно выбранного EXE: исходящий лимит, DSCP, исключения, отдельный UAC и восстановление собственных политик. Процессы Windows/античита защищены.
- DNS: текущие серверы, повторные прямые запросы выбранным резолверам, отдельное изменение IPv4/IPv6 с сохранением static/automatic режима и восстановлением. Шифрованный DNS не заявлен.
- Необязательный NextDNS API: DPAPI CurrentUser key, Allowlist/Denylist, ограниченные статистика/логи по согласию, тест пути NextDNS. Изменение API-конфигурации подтверждается отдельно.
- CPU/RAM общие и выбранного процесса, Working Set, история/экспорт, сравнение равных интервалов «до/после». FPS/GPU/frametime отсутствуют без проверенного измерителя.
- Профили мониторинга CS2/FACEIT/универсальный/пользовательский. Запуск при обнаружении EXE — только по явной настройке с разрешённым диагностическим адресом; завершение игры отменяет сеанс. Системные настройки профилем мониторинга автоматически не применяются.

## Восстановление и ограничения

Сетевой журнал независим от прежних игровых/GPU-журналов; запись сохраняется до изменения, проверяется чтением. Ошибки, неоднозначные частичные изменения и сторонние правки сохраняют журнал и не выдаются за успех. Повреждённый сетевой журнал блокирует запись, но не диагностику. При обычном выходе выполняется восстановление собственных QoS через UAC; после сбоя — отдельной кнопкой. DNS остаётся до явного восстановления. Windows/network reset и flushdns не вызываются.

QoS/DNS и NextDNS API экспериментальны: на этом ПК системная сеть не перенастраивалась и настоящий аккаунт NextDNS не использовался. Нельзя обещать реальное shaping на всех Windows, приоритет DSCP в интернете, совместимость FACEIT AC или выигрыш FPS/ping. UDP-удалённые адреса и байт/с отдельных процессов штатными таблицами не измеряются; список NextDNS-конфигураций может быть недоступен и допускает ручной ID. IPv6-маршрут не определяется. Полная информация о границах и восстановлении — в README.

## Проверено

163 автоматических теста; UI новых/старых вкладок при масштабировании 100/125/150/200%, отсутствие разрешения на пробы, ошибки, отмена и повторное восстановление. Настоящие API проверены только на чтение; loopback ICMP/TCP и CPU/RAM прошли. Настоящее назначение DNS/QoS, другие Windows/драйверы и античит не проверялись.

Сетевые возможности включены в общий релиз 0.7.0 с описанными выше ограничениями.
