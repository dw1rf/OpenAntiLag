# Open AntiLag 0.5.0

- Новый почти чёрный и малиновый дизайн: #02060E / #C50337, вертикальные градиенты, округлая панель статуса и тёмный заголовок Windows.
- Автоматическая проверка GitHub Releases при запуске и каждые 6 часов; фоновая загрузка, проверка SHA-256 и версии, замена EXE с резервной копией и перезапуск приложения.
- Галочка отключения автообновлений и ручная кнопка «Проверить». Beta-релизы и старые версии не устанавливаются автоматически.
- Профиль и сохранённые исходные значения продолжают работать как в 0.4. Обновление ждёт завершения применения/восстановления.

Для перехода с 0.4/0.3 **один раз скачайте EXE вручную**, завершите старую копию через трей и замените файл. Дальнейшие обычные релизы будут загружаться автоматически. Запускайте приложение обычным способом из доступной для записи папки; повышение прав происходит отдельно для изменения системного профиля.

Проверки: 63 теста, сценарий кнопок включения/отключения с имитацией Windows, рендер обычного/узкого окна и масштаба 150/200%, настоящая замена и перезапуск тестовой EXE-копии с сохранением предыдущей версии.

Системные настройки BCD/HAGS/приоритетов по-прежнему экспериментальны. Этот релиз улучшает интерфейс и обновление, но не подтверждает снижение input lag, безопасность любых BCD-настроек на любом ПК или прирост FPS. Реальная запись BCD и загрузка после неё здесь не тестировались.

Windows 10/11 x64, .NET Framework 4.8. Открытые исходники MIT; EXE без цифровой подписи. Перед возвратом к версии 0.3 или старее отключите профиль в новой версии.
