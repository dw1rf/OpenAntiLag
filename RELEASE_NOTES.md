# Open AntiLag 0.6.4 — доступные галочки и отдельное восстановление

Исправлена блокировка всех галочек при активном профиле, ожидании перезагрузки и ошибке проверки. Теперь выбор доступен; применение проверяет условия и показывает причину отказа. Проверка Windows/WMI выполняется в фоне, чтобы не блокировать интерфейс.

На вкладке «Система» добавлена постоянная кнопка «Восстановить основные». Она доступна при заблокированном включении профиля и восстанавливает сохранённые настройки питания, Game Mode, записи Xbox, мыши и таймера без обращения к системному помощнику HAGS/BCD и без UAC.

- Восстановление основных работает даже при недоступном системном журнале.
- Результат или причина ошибки остаются видны под кнопками; после частичной ошибки восстановление можно повторить.
- При отсутствии резервной копии настройки Windows не меняются, галочки возвращаются к начальному выбору.
- Нажатия во время фонового чтения профиля ожидают его завершения; при занятой другой вкладке показывается сообщение.
- Сохранённые HAGS/BCD, требование перезагрузки и GPU-профили не сбрасываются этой кнопкой. Для них остаются отдельные операции восстановления.

Прошли 120 автоматических тестов и UI-проверки, включая восстановление при ошибке системного журнала, отсутствие резервной копии, частичный сбой, повторный откат и доступность включения после восстановления. Настоящие настройки Windows при проверках не менялись.

Исправление цикла обновления из 0.6.2 сохранено. Причину проблемы конкретного ПК без текста ошибки установить нельзя; при оставшейся блокировке посмотрите сообщение над кнопками.
