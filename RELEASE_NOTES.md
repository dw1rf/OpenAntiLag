# Open AntiLag 0.5.5 — AMD Global Graphics

Добавлена вкладка «AMD · Глобальные» с выбором Radeon и кнопками чтения, применения и восстановления через ADLX установленного драйвера AMD. Поддерживаемые параметры: Radeon Anti-Lag, Chill, Boost, Enhanced Sync, Morphological Anti-Aliasing и Wait for Vertical Refresh. Неподдерживаемые функции явно показываются и пропускаются.

Основной набор: Anti-Lag включён (его можно выключить, например для игры с Anti-Lag 2); Chill, Boost, Enhanced Sync и морфологическое сглаживание выключены. Режим минимальной задержки выбирает V-Sync Always Off, второй режим оставляет управление игре (Off unless application specifies). FreeSync и V-Sync в игре для режима без разрывов настраиваются отдельно.

Кнопка меняет глобальные параметры выбранной Radeon; игровые профили могут переопределять их. Не меняются AFMF, RSR, HYPR-RX, фильтрация текстур, FreeSync, FPS-лимит, разгон, частота и разрешение монитора. Anti-Lag 2 включается в игре.

Резервная копия: %LOCALAPPDATA%\OpenAntiLag\amd-backup.xml, с идентификатором PNP видеокарты. Она записывается до изменений. ADLX применяет настройки сразу, поэтому при частичной ошибке остаётся копия для кнопки восстановления. Anti-Lag/Chill/Boost сохраняются и восстанавливаются группой из-за взаимного влияния. При постороннем изменении группы приложение сохраняет её целиком. Для смены набора или GPU сначала восстановите старый набор. Закройте игры и Adrenalin перед записью, не меняйте параметры другими утилитами во время операции.

Поддержка AMD экспериментальная: реальной Radeon на тестовом ПК нет. Проверены 88 тестов, кнопки применения и восстановления на модели драйвера, отсутствие ADLX на NVIDIA, компиляционные проверки C ABI по официальным заголовкам SDK, рендер окна. Это не подтверждает работу записи на реальном AMD-драйвере или снижение задержки.

Локальная версия: %LOCALAPPDATA%\OpenAntiLag\App\OpenAntiLag.exe. Перед запуском закройте предыдущую копию через трей. Путь автозапуска и данные не меняются. В GitHub Releases не опубликовано.
